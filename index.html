2.1 — A linguagem Python

  • Python é uma linguagem de programação de alto nível.
  • Possui sintaxe simples e foco em produtividade.
  • É interpretada e possui tipagem dinâmica.
  • É utilizada em Web, dados, IA, automação, scripts e muito mais.
Ideia principal: o código deve ser legível para facilitar o desenvolvimento e a manutenção.
A linguagem Python3

Primeiro programa

O que acontece?

  • print() é uma função usada para exibir informações.
  • A string está entre aspas.
  • Não precisamos declarar o tipo da variável antes de usar.

Variáveis7

Constantes em Python

Python não possui uma palavra-chave específica para declarar constantes.

Por convenção, usamos MAIÚSCULAS para indicar que um valor não deveria ser alterado.

PI = 3.14159
TAXA_JUROS = 0.10
NOME_SISTEMA = "Acadêmico"
⚠️ A convenção não impede tecnicamente a alteração do valor.

Comparações12

Operadores lógicos

AND

True and True → True
As duas condições precisam ser verdadeiras.

OR

True or False → True
Pelo menos uma condição precisa ser verdadeira.

NOT

not True → False
Inverte o valor lógico.
idade = 20
tem_documento = True

print(idade >= 18 and tem_documento)

Prática guiada — Média do aluno
